# Golden-Crust
FSCJ Web Development Final Project

This project was created as my final project for the Web Development program at Florida State College at Jacksonville. It demonstrates the web development skills I developed during the program, including HTML, CSS, Web Structure, responsive design, and user-focused page organization.

Project Objective:
 The Golden Crust was created as a final web development project to demonstrate the skills developed throughout the course. The project focuses on building a professional, visually cohesive bakery website that combines thoughtful branding, clear navigation, responsive page design, and engaging content centered around a fictional Cantonese bakery in New York City.
